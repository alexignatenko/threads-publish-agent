Опубликуй в Threads: $ARGUMENTS

Правила без исключений:

1. Сначала `doctor` — проверь аккаунт и остаток квоты.
2. Покажи предпросмотр (команда без `--yes`) и дождись явного подтверждения текста.
3. Только после подтверждения запусти команду с `--yes`.
4. Проверь в ответе `"published": true` и отдай пользователю `permalink`.

Публикация необратима: API не умеет ни редактировать, ни удалять посты.

Если речь об очереди — `queue list --due`, затем `queue run --yes`.
