---
description: Настроить публикации в Threads с нуля — доступ, голос, правила публикации
---

Проведи полный онбординг скилла `threads-publishing`.

1. Запусти `doctor` и определи, что уже настроено.
2. Прочитай `references/setup.md` и пройди все этапы по порядку: окружение, приложение
   в Meta for Developers с получением маркера, интервью о правилах публикации, профиль
   голоса, проверка.
3. Вопросы задавай порциями по 2–4, с вариантом по умолчанию в каждом.
4. Ключи приложения не спрашивай: для своего аккаунта они не нужны. Токен сохраняй
   через CLI, в переписке не повторяй.

Если пользователь добавил аргументы — учти их как контекст: $ARGUMENTS
