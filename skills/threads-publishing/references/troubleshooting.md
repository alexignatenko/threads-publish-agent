# Разбор ошибок

Сначала `$T doctor` — он показывает, на каком уровне проблема. В ответах CLI есть поле `hint`:
читай его, там обычно уже написано, что делать.

---

## Настройка и токены

| Что видишь | Причина | Что делать |
| --- | --- | --- |
| код 3, `Профиль не настроен` | Нет `config.json` | `$T config init`, затем онбординг (`references/setup.md`). |
| код 4, `Нет access_token` | Токен не сохранён | `references/setup.md`, этапы 3–4: сгенерировать маркер и сохранить. |
| `Токен истёк` | Прошло больше 60 дней без продления | Продлить нельзя, нужен новый: сгенерируй маркер заново в разделе «Генератор маркеров пользователя». |
| `Токен младше 24 часов` при `refresh` | Threads не даёт продлевать свежие токены | Ничего делать не нужно — `doctor` продлит, когда придёт время. |
| `Продление токена выключено в настройках` | `auth.allow_refresh=false` или `refresh_when_days_left=0` | Так настроено специально, если токен делится с другим сервисом. Продлить всё равно: `auth refresh --force`. Сначала спроси пользователя. |
| Другой сервис с тем же токеном перестал работать | Кто-то продлил токен, и старая строка отвалилась | Выключить автопродление здесь (`auth.allow_refresh=false`) и выдать другому сервису актуальный токен. Надёжнее — отдельное приложение Meta для каждого. |
| Форма настроек не сохраняется: «Укажите URI переадресации для OAuth» | Поля с адресами нужны только для входа через браузер | На основном пути уйди со страницы не сохраняя — генератору маркеров они не нужны. |
| В генераторе маркеров нет кнопки добавить аккаунт или маркер не выдаётся | Аккаунт Threads приватный | Маркеры выдаются только для общедоступных аккаунтов. |

## Доступ и права

| Что видишь | Причина | Что делать |
| --- | --- | --- |
| `403` при публикации, `me` при этом работает | У токена нет `threads_content_publish`, либо аккаунт не принял приглашение тестировщика | Сначала добавить разрешение в настройках приложения — без этого перевыпуск ничего не даст. Потом выпустить маркер заново. Проверить приглашение в Threads → Настройки → Сайты и приложения. |
| `403` на `insights` | Нет `threads_manage_insights` | Добавить разрешение в настройках приложения, затем выпустить маркер заново. |
| `403` на `replies` / `hide` | Нет `threads_read_replies` / `threads_manage_replies` | То же: сначала разрешение в приложении, потом новый маркер. |
| `api_quota` в `doctor` = false, остальное ок | `threads_publishing_limit` требует `threads_content_publish` | Публиковать всё равно не получится: добавить разрешение в приложении и выпустить маркер заново. |
| Ошибка про App Review при публикации в чужой аккаунт | Приложение в режиме разработки | Публиковать можно только в аккаунты-тестировщики. Для остальных нужен App Review у Meta. |

## Публикация

| Что видишь | Причина | Что делать |
| --- | --- | --- |
| `"published": false, "dry_run": true` | Нет `--yes` — это предпросмотр, а не ошибка | Согласовать текст с пользователем и повторить с `--yes`. |
| `text длиной N символов, лимит 500` | Слишком длинный текст | Сократить или сделать цепочку (`references/writing.md`). |
| `Текст содержит запрещённые слова` | Сработал `safety.blocked_words` | Поправить текст. Список менять только с разрешения пользователя. |
| `Публикация остановлена: локальный лимит` | Упёрлись в `safety.max_posts_per_day` | Сказать пользователю, предложить поднять лимит. Молча не обходить. |
| `Контейнер … в статусе ERROR` | Медиа не скачалось или формат не поддержан | Проверить, что URL публичный HTTPS и отдаёт файл напрямую (не страницу). Для картинок — JPEG/PNG, для видео — MP4/MOV. |
| `Контейнер не обработался за N сек` | Долгое видео | `--timeout 600`. Контейнер живёт ограниченное время, потом `EXPIRED` — тогда создавать заново. |
| `"partial": true` у цепочки | Цепочка оборвалась посередине | **Не публиковать заново.** Продолжить с последнего id: `$T post --reply-to <id> --text "…" --yes`. |
| `429` от API | Лимит 250 постов / 1000 ответов за 24 ч | `$T quota` покажет остаток. Ждать. |
| Пост ушёл, но с опечаткой | API не умеет редактировать и удалять | Исправить нельзя. Удалить можно только вручную в приложении Threads. Сказать пользователю честно. |

## Сеть и окружение

| Что видишь | Причина | Что делать |
| --- | --- | --- |
| `Сеть недоступна: Tunnel connection failed: 403` | Прокси/политика сети блокирует `graph.threads.net` | Проверить `HTTPS_PROXY` и политику сети. В песочницах и CI домен часто закрыт — там публикация не заработает. |
| `Сеть недоступна: timed out` | Нет интернета или тормозит | Повторить; CLI сам делает 3 попытки с паузами. |
| `selftest` падает | Повреждён скрипт или Python старше 3.8 | `python3 --version`; переустановить скилл. |
| `ModuleNotFoundError` | Не должно случаться — зависимостей нет | Значит запущен не тот файл. Проверить путь к `threads.py`. |

## Данные профиля

| Задача | Как |
| --- | --- |
| Где всё лежит | `$T config path` |
| Посмотреть настройки и замаскированные секреты | `$T config show` |
| Второй аккаунт | `$T --profile brand config init`, дальше все команды с `--profile brand` |
| Перенести на другую машину | Скопировать каталог профиля. Внутри `credentials.json` с токеном — переносить только защищённым каналом. |
| Отозвать доступ | `$T auth logout` убирает токен локально. Полностью — удалить приложение или отозвать доступ в Threads → Настройки → Сайты и приложения. |
| Начать с нуля | `$T config init --force` перезапишет `config.json`; `voice.md` и очередь останутся — удалять их вручную. |

## Когда останавливаться и спрашивать

- Не можешь понять, тот ли аккаунт подключён → покажи `username` из `doctor` и спроси.
- Ошибка повторяется дважды после исправления → не пробуй третий вариант наугад,
  опиши пользователю, что видишь, и что проверил.
- Требуется изменить `safety`, отключить подтверждение или обойти лимит → только с прямого
  разрешения пользователя, с объяснением последствий.
